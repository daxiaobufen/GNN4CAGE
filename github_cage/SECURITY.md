# Security Policy

## Supported Versions

Only the latest commit on the default branch is supported for security fixes.

## Reporting a Vulnerability

Please report potential vulnerabilities privately before public disclosure.

- Contact: open a private security report to the repository maintainers.
- Include: affected files/scripts, reproduction steps, expected vs actual behavior, and impact.
- Response target: initial acknowledgement within 7 business days.

Please do not publish exploit details before maintainers have time to assess and patch.
